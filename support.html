Getting Started
Your step-by-step guide to using LearnTogether
1
Receive Your Account
Your account is created by the platform administrator. You will receive a username and password. Regular users cannot self-register — only the admin can create accounts.
2
Log In
Go to the LearnTogether portal. Click the User Login tab. Enter your username and password provided by your administrator. Click Sign In.
3
Browse Courses
After logging in you will see the Courses page. Use the search bar to find specific topics, or click the category filters (Frontend, Backend, Design, Database, DevOps) to narrow down the list.
4
Open a Course
Click the ↗ Open button next to any course. A confirmation dialog will appear showing the URL. Click Open ↗ to launch the resource in a new tab.
5
Mark Courses Complete
Once you finish a course, click the circle ○ button next to it to mark it as complete ✓. Your progress percentage will update automatically. Complete all courses to earn a certificate!
6
Bookmark Courses
Click the 🔖 bookmark icon on any course to save it for quick access later. View all your bookmarks from the profile menu in the top right corner.
7
Rate and Review
Click on the star rating area of any course to open the reviews panel. You can leave a star rating and written review to help other learners. Each user can review each course once.
8
Change Your Password
Click your profile avatar in the top right → select Change Password. Enter your current password and your new password twice. Click Update Password.
Frequently Asked Questions
Common questions from users and administrators
I forgot my password — what do I do? +
Since LearnTogether uses username/password accounts (not email for regular users), password resets must be done by the platform administrator. Contact your admin and ask them to update your password. The admin can create a new password for you from the Users tab in the admin panel.
Why can't I sign up myself? +
LearnTogether is a private, invite-only platform. User accounts are created exclusively by the platform administrator. This ensures controlled access to the learning portal. Contact your administrator to request an account.
My progress is not saving — what's wrong? +
Progress is saved to the cloud in real time. If your progress is not showing: 1) Make sure you clicked the ○ circle button (it turns green ✓ when complete). 2) Check your internet connection. 3) Try refreshing the page. 4) If the issue persists, log out and log back in.
A course link is not working or showing a 404 error +
LearnTogether links to external resources on third-party websites. Sometimes those pages move or get removed. Contact your platform administrator and let them know which course link is broken so they can update it with a working URL.
How do I earn the completion certificate? +
Complete every course in the portal by clicking the ○ button on each one until it turns green ✓. When your progress reaches 100%, a certificate popup will automatically appear. You can then download it as a text file. The certificate is for personal motivation — it is not an accredited qualification.
Can I use LearnTogether on my phone? +
Yes! LearnTogether is fully responsive and works on smartphones, tablets, and desktop computers. Simply open the portal URL in your mobile browser and log in as normal.
How do I switch between dark and light mode? +
Click the 🌙 moon icon in the top right navigation bar to toggle between dark mode and light mode. Your preference is remembered automatically for your next visit.
I am an admin — how do I log out securely? +
Admin accounts use OTP (one-time password) verification for logout. When you click Logout, a 6-digit code will be shown in a toast notification at the bottom right of the screen. Enter that code in the popup to confirm logout. This extra step protects your admin account from unauthorised logouts.
How do I import multiple users at once as admin? +
Go to the Settings tab in the admin panel. Scroll to the Bulk Import section. Create a CSV file with this format — one user per line: username,password. Drag and drop the file or click to upload. Review the preview and click Import Users. Duplicate usernames are automatically skipped.
The portal shows a "locked" screen when I try to log in +
The platform administrator has temporarily locked the portal, usually for maintenance. The lock screen shows a message with the reason. Contact your administrator directly to find out when the portal will be back online.
I got a "Missing or insufficient permissions" error +
This is a database permissions error. If you are an administrator, go to the Firebase Console → Firestore Database → Rules tab and ensure the security rules are published correctly. If you are a regular user, contact your administrator as the database rules may need to be updated.
Common Issues
Step-by-step fixes for the most common problems
⛔ Login Issue
Cannot log in to my account
  1. Check username is correct (case-sensitive)
  2. Check password has no extra spaces
  3. Try clearing browser cache → Ctrl+Shift+R
  4. Try a different browser
  5. Contact admin to reset password
⛔ Page Issue
Page appears blank or broken
  1. Press Ctrl+Shift+R (hard refresh)
  2. Clear browser cache and cookies
  3. Disable browser extensions temporarily
  4. Try in incognito/private window
  5. Try a different browser (Chrome recommended)
⛔ Email Issue
Verification email not received
  1. Check Spam / Junk folder first
  2. Search for "learntogether" or "firebaseapp"
  3. Mark as Not Spam if found there
  4. Wait 5 minutes and check again
  5. Try signing up again with same email
⛔ Progress Issue
Progress not updating correctly
  1. Ensure you clicked the ○ circle button
  2. Check it turned green ✓
  3. Check internet connection is stable
  4. Refresh the page to reload from database
  5. Log out and log back in
⛔ Admin Issue
Admin login says "not authorized"
  1. Make sure you verified your email first
  2. Check spam folder for verification email
  3. Ensure you are using the exact email used during signup
  4. Check Firebase Console → Authentication to confirm account exists
  5. Try creating admin account again if needed
⛔ Deploy Issue
Site shows Firebase default page after deploy
  1. Ensure your file is named exactly index.html
  2. Confirm it is inside the project folder
  3. Check firebase.json has "public": "."
  4. Run firebase deploy again
  5. Hard refresh with Ctrl+Shift+R
